# Mahawar Garments

> **"Where Tradition Meets Modern Style"**  
> Luxury Indian Ethnic, Occasion & Contemporary Formal Wear — Flagship Atelier in Chandni Chowk, Delhi.

---

## Brand Overview
Mahawar Garments is an established Indian fashion house rooted in the heritage of Chandni Chowk, Delhi. This digital landing page is designed with an editorial luxury aesthetic, combining traditional Indian royal craftsmanship with modern sartorial tailoring.

---

## Design System & Palette

- **Ivory (`#F7F1E8`)** & **Warm Cream (`#EFE4D3`)** — Primary editorial canvas
- **Deep Burgundy (`#541B1B`)** & **Dark Maroon (`#3D1111`)** — Brand accent & typography
- **Warm Beige (`#C9AE8A`)** — Secondary warmth
- **Muted Gold (`#B99A63`)** — Subtle luxury highlights
- **Charcoal (`#24201E`)** — Body copy

---

## Key Features & Structure

- **Luxury Navigation**: Sticky header with authentic suit-crest brand logo, search modal trigger, interactive wishlist counter, and curated collection bag drawer.
- **Cinematic Hero**: Split editorial composition with Indian couture imagery, gold accents, dual CTAs, and scroll indicator.
- **Curated Categories**: Interactive image cards for *Men*, *Women*, *Kids*, and *Occasion Wear*.
- **Curated for Every Occasion**: Editorial showcase for *Weddings*, *Festive*, *Formal*, and *Everyday*.
- **The Modern Man**: Asymmetric menswear feature with interactive category chips (*Suits, Blazers, Kurtas, Sherwanis, Nehru Jackets, Indo-Western*).
- **Mahawar Signatures**: 6 flagship garments with dynamic quickview modals, pricing, and bespoke enquiry triggers.
- **Craftsmanship & Atelier Privileges**: Highlights on fabrics, zardozi hand-embroidery, custom tailoring, express alterations, and delivery.
- **Chandni Chowk Atelier**: Boutique address, store timings, direct WhatsApp/phone/email actions, and styled interactive Delhi map card.
- **100% Responsive**: Tested across iPhone, iPad, Android, and 4K desktop viewports.

## Getting Started Locally

Open `index.html` directly in your browser, or start a local dev server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```
